# Dialogs Examples

Dev solution only. It links the Toolkit projects and builds the framework and Windows TFMs from `Directory.Build.props`. `Krypton.Dialogs` is not a separate NuGet package. The Nuget arm of the example project uses `Krypton.Standard.Toolkit.Canary`.

# Krypton File Operation Example

Copy, move, rename, recycle, and permanent delete through `KryptonFileOperation`, including a name-conflict prompt and a longer copy that keeps the progress dialog open.
